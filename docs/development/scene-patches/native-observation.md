# Record the native fixed-placement journey

Traces captured outside an identified active world carry `sourceLifecycle: unassigned` and a null `sourceLoadId`. They emit as `unassigned-attempt-trace` and remain separate from active-world counts. A deliberate replay after observer readiness measures same-engine retries without silently attributing early callbacks to a later world.

This test-only mod records observations for the fixed-placement fixture. It does not install itself or start the game. Build it against the installed game assemblies, placing all build outputs outside the repository:

```powershell
dotnet build Tests/NativeObservation/NativeObservation.csproj -p:GameManaged='<Railroader_Data/Managed>' -p:BaseIntermediateOutputPath=C:/TMP/Issue39ObservationBuild/obj/ -p:OutputPath=C:/TMP/Issue39ObservationBuild/bin/
```

A later authorized test must install `NativeObservation.dll` and `Info.json` in `C:/TMP/RailroaderMapResearch/RuntimeHome/Mods/Issue39Observation`. The observer checks the sole `-homedir` argument, its mod directory and active map `crankyant/fixed-placement-fixture-map` before recording or exposing controls. It writes `Evidence/<loadId>/observations.jsonl` under that mod directory. The observer creates a fresh load ID for each world load. Preserve the complete evidence directory with the corresponding build and fixture provenance.

Use the explicit baseline, after and restoration snapshot buttons at the intended phases. A successful snapshot contains one unique Sylva board in BushnellWhittier-MapManager, origin conversion, the T-47 marker and graph registrations, culler token and sphere, mask modifier descriptors and targets, and terrain pending/idle state. A `snapshot-error` means that phase is incomplete. `OnTileBuilt` events contain native map-coordinate bounds. JSONL rows carry schema and evidence kind, event sequence, load ID, frame, UTC, process ID, and SHA-256 hashes of the loaded Railroader, observer and patcher assemblies. Startup attempt traces can precede observer readiness; buffered rows retain their original `sourceFrame`, while their sequence identifies when they were written. Trace capture requires a separately built instrumented patcher; the observer does not patch native methods.

The replay button explicitly calls the current patcher application callback once and records whether the engine reference stayed the same. It is a diagnostic action, not a native world reload. The observer also takes snapshots on the mutation, applied, restore-request and restore-result trace stages while it is ready. Buffered startup traces cannot recover an earlier snapshot. Capture the baseline in an unmodified fixture session with the patcher engine loaded before generating the test document. The generator produces `Baseline.json`; copy it to the observer pack through the test-home preparation command. Its shape is `{ "schemaVersion": 1, "snapshot": <selected baseline JSON object> }`. On later loads the observer validates its identity and uses its board map position for both tree sample regions. It records the original process, load, graph, scene and board identities in `referenceSource`. An invalid file is reported in `referenceError` and `measurementErrors`; its presence disables baseline recapture. Snapshot methods do not set object poses, activity, hierarchy, graph registrations, masks or terrain. The explicit replay control can change targets through production application. Focus board and Focus T-47 move the native strategy camera and can trigger floating-origin movement. Snapshot labels are operator claims, not proof that application or restoration occurred. Compare state and trace events and inspect errors before drawing a conclusion. The probe was used in an isolated Railroader 0.6.2 build 26335745 journey. Snapshot labels alone remain insufficient evidence; compare the recorded poses, registrations and terrain state. Generated-tree samples count and hash native array entries within 20 m of the baseline position and baseline plus 5 m, and record the native handoff and loaded array relationships. They also record interpolated map height at each sample point. They do not inspect the complete heightmap or rendered pixels.
