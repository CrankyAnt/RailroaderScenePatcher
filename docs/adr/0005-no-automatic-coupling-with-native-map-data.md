# No automatic coupling between scene objects and native map data

A scene object does not follow native map data, such as a track span, industry position, Prop, spawn or passenger stop, when that data moves or changes, and the patch contract has no following relation between them. A modder aligns each scene object with its native counterpart by its own edit, while native map data stays with the native editor. The game keeps the two as separate objects without a link between them: moving the native Bryson depot Prop left its baked fixtures group at the old place. A coupling rule would need its own pairing and movement semantics for objects the game does not pair, and once MapMods ship independent placements, adding automatic following would move objects in distributed documents. The cost is that a later move of the native counterpart leaves the aligned scene object behind until the modder moves it too. See [the operation scope in #38](https://github.com/CrankyAnt/RailroaderScenePatcher/issues/38) and [finding #80](https://github.com/CrankyAnt/RailroaderScenePatcher/issues/80).
