# Early repair mutation probe

This disposable research probe tests one known fixture. It reads `repair-case.txt` from its own mod directory and only accepts the exact M5pp, Shuo and SCrankyAntSceneProbe test tuple. Before setting the location it checks the active map, hierarchy path, matching markers in all valid scenes, including loading scenes, fixture pack count, original location, absent old segment, replacement endpoint IDs and replacement resolution. It then always leaves native `TrackMarker.OnEnable` to execute. The postfix counts registrations and checks the registered object. A setter error may occur after a partial mutation. End a failed test without saving and inspect both before and after logs. This is not a production patch format, ownership test, rollback implementation or general safety claim.

Unless a `SKIP_CONTROL` file is present, the `OnWorldLoad` control uses `MessageLog.Warning` with a unique research key and clearly identifies the simulated failure. It is not a real patch failure. The log's non-null return only indicates a retained object, not player-visible presentation. Inspect the native Log window separately. This probe does not remove messages or close windows.

Build outside the checkout using the same .NET SDK and pinned Harmony dependency as the observer:

```powershell
dotnet build Research/EarlyRepairMutationProbe/EarlyRepairMutationProbe.csproj -p:GameManaged='D:\SteamLibrary\steamapps\common\Railroader\Railroader_Data\Managed' -p:BaseIntermediateOutputPath='C:\TMP\EarlyRepairMutationProbe\obj\' -p:OutputPath='C:\TMP\EarlyRepairMutationProbe\bin\'
```
