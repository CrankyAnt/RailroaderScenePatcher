# Community-search evidence

Research date: 2026-11-07. A targeted search of Railroader modding discussions did not establish a native experimental 0.6 JSON mechanism for rebinding existing scene-authored TrackMarker components. Search coverage was bounded; this does not prove that no undocumented or external mechanism exists.

A legacy JSON crossing-editing example relied on a separately installed runtime and Unity Mod Manager. The public package reference is [Latom's Crossings Editable](https://www.nexusmods.com/railroader/mods/1525). That example does not establish compatibility with experimental 0.6 or a native scene-override feature.

Searches included TrackMarker, track marker, faulty triggers, markers, scene, scene json, crossing json, markers edit, crossing editor and marker json. Broad result sets were sampled rather than exhaustively read. Community experience was treated as a lead; owning loader code and official documentation remained necessary to establish support.

Individual community identities, restricted message links and session-operation details are omitted from this publication copy. No private messages or conversations are reproduced.
