# Railroader 0.6 rework JSON examples

Research date: 2026-11-07. This is a bounded search, not proof that no undocumented mechanism exists.

No independently inspected published 0.6 mod or official example showed a JSON patch changing, disabling, or retargeting an existing Unity-scene `TrackMarker`. Sox's Ela archive was available to the parent investigation, but this search did not independently inspect it. The public Nexus file endpoint for mod 2040 returned HTTP 403 to the research browser, so the archive contents and exact archive filename remain unverified.

[East Whittier MoW Yard TCT26](https://www.nexusmods.com/railroader/mods/2040) is a 0.6 experimental MoW yard rework. It is a relevant base-map rework candidate. An earlier search lead about track-marker warnings was not independently verified from the accessible posts and is not treated as an established author statement. The later version-scoped sandbox test is recorded in Scope/Tests/02-EastWhittier/Result.md. The listing shows one file, version 1. If further inspection is useful, request the main file by mod title; its exact archive filename is unknown.

[Nikii's Bryson City Industries](https://www.nexusmods.com/railroader/mods/2003?tab=files) lists the main file `Nikii's Bryson City Industries`, version 1, 3 KB. Its [description](https://www.nexusmods.com/railroader/mods/2003) requires 0.6.x experimental and describes additions, not marker fixes. The archive was not inspected.

[Tile Editor schema examples](https://github.com/F-U-S-E-E/Tile_Editor/blob/main/docs/SCHEMA_EXAMPLES.md#grade-crossings) provide `grade-crossings.json`, with `nodeId`, optional `segmentIds` and `enabled`. The document explicitly names `Hrogers.CrossingRuntime` as its reader, says to ship or install that runtime, and describes registering crossing markers. Setting `enabled` false applies to an entry in this runtime's own file, not a demonstrated override of an existing scene marker. The document also uses 'native' for FUSE packages; this does not mean Railroader's native 0.6 JSON loader reads the file. Runtime compatibility with 0.6 was not established. [A published mod](https://www.nexusmods.com/railroader/mods/1754) independently names that runtime as needed for its crossing markers.

[Data.rl](https://docs.railroadergame.com/modding/data-rl/) documents `modifyDefinitions` on definition dictionaries and `modifyMap` on parsed map JSON before deserialization. `map.merge` recursively merges objects, deletes keys with null, and replaces arrays wholesale. Its example changes `ops.areas.whittier.industries.whittier-sawmill.components.logs.carUnloadRate`. This is a serialized industry component example, not an example of modifying a Unity scene component. A file loaded with `json.load` provides data to a script; its presence alone does not establish another scene-override loader.

The [map modding documentation](https://docs.railroadergame.com/modding/map-modding/) says base-map signals, progression, bridges and some scenery remain in an internal Unity scene, which loads with a layered map. It documents `objects` JSON for prop placements and style overrides. It does not document targeting an existing scene object or `TrackMarker` through this structure. The [0.6 release notes](https://docs.railroadergame.com/release-notes/0-6-0/) identify `world.getMapObject` as a Relay API. That mention does not show a marker setter or prove access to these scene components.

[ARC Whittier](https://www.nexusmods.com/railroader/mods/430) is an older mod whose changelog mentions 2024.6.6b experimental. Its mod version 0.6 must not be confused with game version 0.6. [A legacy rework support thread](https://www.nexusmods.com/railroader/mods/542?tab=posts) shows `StrangeCustoms.Tracks.GraphPatcher` and its own array-patch syntax, not evidence of native 0.6 behavior. [Community feedback](https://community.railroadergame.com/t/mow-content-creator-feedback/227) compares legacy and 0.6 tooling but offers no evidenced marker retargeting API in the retrieved discussion.

The documented patch example supports modifying data actually present in parsed map JSON or definitions. No verified `sceneObjects` or marker patch schema was found. An undocumented loader or Relay operation remains possible.

The Nexus authors of both current mods require permission to modify their files or use their assets and prohibit reupload to other sites. The older ARC Whittier page says its mod is public domain. Consult linked pages for complete terms. No external archives were downloaded, installed, executed, copied, or modified for this research.
